# HireSync – Employer-Applicant Interaction Platform

HireSync is a full-stack recruitment platform designed to streamline the hiring process with real-time communication and integrated video interviews. It connects employers with potential candidates through intuitive job posting, applicant tracking, live chat, and custom evaluation tools.

## 🚀 Features

- **Job Posting & Applicant Tracking**  
  Employers can post job listings and track applicants through a centralized dashboard.

- **Video Interviews via ZEGOCLOUD**  
  Conduct seamless, high-quality video interviews directly within the platform using ZEGOCLOUD integration.

- **Real-Time Chat with WebSocket**  
  Engage in real-time conversations between employers and applicants using WebSockets for instant messaging.

- **Custom Test Creation for Candidate Evaluation**  
  Employers can design and assign custom tests to better assess candidates' skills.

## 🛠️ Tech Stack

**Frontend:**  
- React.js

**Backend:**  
- Node.js  
- Express.js

**Database:**  
- MongoDB

**Real-Time Communication:**  
- WebSocket (e.g., Socket.io)

**Video Communication:**  
- ZEGOCLOUD
